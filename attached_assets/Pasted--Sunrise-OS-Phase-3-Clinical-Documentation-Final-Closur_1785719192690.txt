1. Login as nurse.
2. Create a nursing note.
3. Save and sign.
4. Confirm note type and author.

## Supervisor flow

1. Login as supervisor.
2. Open signed note.
3. Void with a reason.
4. Confirm original content remains visible.
5. Confirm void status, reason, actor, and timestamp.
6. Confirm the note cannot be edited.

## Authorization flow

1. Other-facility clinician cannot access the note.
2. Unassigned clinician cannot access the note.
3. Security administrator without a clinical role cannot access it.
4. HR cannot access it.
5. Billing cannot access it.
6. Another clinician cannot edit the author’s draft.

## Concurrency flow

1. Open one draft in browser session A.
2. Open it in browser session B.
3. Save from A.
4. Attempt stale save from B.
5. Confirm HTTP 409.
6. Confirm B’s unsaved content is preserved.
7. Confirm reload/retry guidance is displayed.

The browser tests must fail—not silently skip—when the required environment is unavailable.
